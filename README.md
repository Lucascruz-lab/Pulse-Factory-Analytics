# Pulse Factory Analytics

Projeto prático de Análise de Dados utilizando PostgreSQL, SQL e Python.

## Objetivo

Desenvolver habilidades em análise de dados por meio de construção de indicadores e consultas SQL aplicadas a um cenário de produção.

## Tecnologias 

- PostgreSQL
- DBeaver
- SQL
- Python (em desenvolvimento)
- Git
- GitHub
