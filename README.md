# Pulse Factory Analytics

Projeto prático de Análise de Dados utilizando PostgreSQL, SQL e Python.

## Objetivo

O objetivo deste projeto é evoluir do básico ao avançado em Analise de Dados, documentando cada etapa do aprendizado e transformando cada aula em uma entrega prática para o Github.

## Tecnologias 

- PostgreSQL
- DBeaver
- SQL
- Python *(em desenvolvimento)*
- Glooge Sheets *(próxima etapa)*
- Power BI *(próxima etapa)*
- Git
- GitHub
